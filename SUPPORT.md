# Support

Use [GitHub Discussions](https://github.com/SelmiAbderrahim/pssmngr/discussions) for setup questions and design conversations. Use [GitHub Issues](https://github.com/SelmiAbderrahim/pssmngr/issues) for reproducible bugs and concrete feature proposals.

Before posting:

- check the README and `docs/`;
- search existing issues and discussions;
- include the pssmngr commit or release, operating system, Docker/Compose versions, relevant configuration with secrets redacted, and concise logs;
- replace domains, email addresses, tokens, IDs, ciphertext, and other user-specific data with synthetic values.

Community support is best effort and has no guaranteed response time.

Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md). Never attach a `.env`, recovery kit, database dump, vault export, or full production log to a public thread.
