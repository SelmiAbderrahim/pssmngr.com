# Code of Conduct

## Our standard

We expect respectful, constructive, and evidence-based participation in every project space.

Positive behavior includes welcoming people with different backgrounds and experience levels, discussing ideas rather than attacking people, accepting correction, protecting private information, and giving security reports appropriate confidentiality.

Unacceptable behavior includes harassment, discriminatory language, threats, doxxing, spam, sustained disruption, sexualized conduct, or knowingly publishing an unpatched vulnerability or real user secret.

## Enforcement

Project maintainers may edit or remove content, close threads, reject contributions, or temporarily or permanently restrict participation when behavior violates this policy. Enforcement decisions should consider severity, context, repetition, and community safety.

For an ordinary moderation concern, contact the maintainers through their GitHub profiles listed in [MAINTAINERS.md](MAINTAINERS.md) and include links or screenshots needed to understand the report. Do not use a public thread if doing so would expose private information.

Security vulnerabilities must use the private process in [SECURITY.md](SECURITY.md).

## Scope

This policy applies in the repository, issues, pull requests, discussions, release channels, and other project spaces controlled by the maintainers.

This code is adapted from the principles of the Contributor Covenant 2.1.
