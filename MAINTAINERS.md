# Maintainers

| --- | --- | --- |
| Selmi Abderrahim | [@SelmiAbderrahim](https://github.com/SelmiAbderrahim) | Project direction, releases, security response, and repository-wide review |

Maintainers review contributions, protect the zero-knowledge boundary, coordinate security fixes, manage releases, and apply the project governance and conduct policies.

Maintainer access is granted after a sustained record of technically sound contributions, constructive review, reliable security judgment, and alignment with the project's public-interest goals. The current maintainers decide additions and may define narrower ownership areas as the team grows.

Inactive maintainers may move to emeritus status. Changes to this file are reviewed like any other governance change.
